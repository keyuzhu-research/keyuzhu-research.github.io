# Keyu Zhu — Academic Website

Personal academic website of Keyu Zhu, master's student at East China Normal University.

**Website:** https://keyuzhu-research.github.io/

**Research:** Urban accessibility, spatial equity, 15-minute cities, and GIS.

**Selected publication:** [Cities, 2026, Article 107506](https://doi.org/10.1016/j.cities.2026.107506).

**ORCID:** https://orcid.org/0009-0004-9594-2611

This site is based on the open-source Academic Pages Jekyll template. Academic Pages template and its original license are retained in the repository history and LICENSE file.

To add the design portfolio PDF, upload it as `files/portfolio.pdf`. The `/portfolio/` page will display it automatically.

To add a downloadable CV, upload it as `files/cv.pdf`.
